# SQL Database Practice

A practical relational database project created using Microsoft SQL Server and SQL Server Management Studio.

## What this project covers

- Database and table creation
- Primary and foreign keys
- Data insertion
- SELECT queries
- WHERE filtering
- ORDER BY sorting
- Aliases
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- SELF JOIN
- QA-style data validation queries

## Database structure

The project contains two main tables:

### Departments
- department_id
- department_name

### Employees
- employee_id
- employee_name
- salary
- department_id
- manager_id

## QA-style checks

The SQL script includes queries to:

- Find employees without departments
- Find departments without employees
- Identify employees earning above a selected salary
- Display employee-manager relationships
- Validate table relationships
